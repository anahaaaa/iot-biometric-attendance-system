# Abstract

The IoT-Based Biometric Attendance System is designed to streamline attendance monitoring in educational institutions and corporate environments through advanced biometric technology.
By integrating an R307 fingerprint sensor with the ESP8266 NodeMCU, the system ensures secure and accurate identification of individuals.
Leveraging the MQTT protocol for efficient communication, the system captures fingerprint data upon interaction and securely transmits attendance information to AWS IoT Core for cloud-based storage.
Each attendance record is timestamped, providing a reliable and real-time log of attendance events. A web-based administrative interface enables administrators to manage attendance records, monitor real-time data, and generate reports efficiently.
The integration of cloud storage ensures accessibility, scalability, and improved data security. This project demonstrates the practical implementation of IoT, cloud computing, and biometric authentication technologies to create a reliable,
scalable, and automated attendance management solution that minimizes manual errors and enhances operational efficiency.
