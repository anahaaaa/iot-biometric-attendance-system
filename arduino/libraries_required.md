# Required Arduino Libraries

Install the following libraries using the Arduino IDE Library Manager before uploading the code.

## Libraries Used

1. Adafruit Fingerprint Sensor Library
2. ESP8266WiFi
3. PubSubClient
4. ArduinoJson
5. SoftwareSerial
6. WiFiClientSecure

---

## Installation Steps

1. Open Arduino IDE
2. Go to:
   Sketch → Include Library → Manage Libraries
3. Search and install the required libraries

---

## Recommended Arduino IDE Version

- Arduino IDE 2.x
